GitHub 토큰으로 연결

토큰은 이 브라우저(localStorage)에만 저장되고 GitHub 말고는 어디에도 보내지 않습니다. 공용 PC에서는 작업 후 꼭 로그아웃(토큰 지우기)을 누르세요.

토큰 발급 방법

  1. github.com 로그인 → 오른쪽 위 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름은 아무거나(예: 직무사전 관리), 만료일은 원하는 기간으로
  4. Repository access: Only select repositories → jobzorro/jobzorro-site 선택
  5. Permissions → Repository permissions → Contents: Read and write
  6. 맨 아래 Generate token → 나온 토큰(github_pat_로 시작)을 복사해 왼쪽 칸에 붙여넣기

토큰은 발급 화면에서 한 번만 보입니다. 잃어버리면 새로 발급하면 됩니다. 만료되면 이 화면이 다시 뜹니다.
