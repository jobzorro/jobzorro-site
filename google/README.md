# 상담 신청 폼 → 구글 시트 연동 (5분)

사이트의 "무료 상담 신청하기" 버튼은 `apply/index.html` 폼으로 갑니다.
폼은 서버 없이 **구글 Apps Script 웹앱**으로 전송되고, 웹앱이 구글 시트에 한 줄씩 적습니다. 신청이 오면 메일로 알려 주고, 아래 "카카오톡 알림 설정"까지 마치면 **내 카카오톡으로도 바로** 알림이 옵니다.

## 1. 시트 만들기
1. https://sheets.new 에서 새 시트를 만들고 이름을 `취업조로 상담신청`으로 바꿉니다.
2. 메뉴 **확장 프로그램 > Apps Script** 를 엽니다.
3. 편집기의 기본 코드를 지우고 `google/apps_script.gs` 내용을 전부 붙여 넣습니다.
4. 맨 위 `NOTIFY_EMAIL` 에는 운영자 메일(`zzorro0382@gmail.com`)이 들어 있습니다. 다른 주소로 받으려면 바꾸고, 메일 알림이 필요 없으면 `""` 로 비웁니다.
5. 저장(Ctrl+S) 후 함수 선택 상자에서 `testInsert` 를 고르고 ▶ 실행 → 권한 승인 창이 뜨면 본인 계정으로 허용.
   시트에 `상담신청` 탭과 테스트 행이 생기면 정상입니다. 테스트 행은 지워도 됩니다.

## 2. 웹앱으로 배포
1. 오른쪽 위 **배포 > 새 배포**.
2. 톱니바퀴에서 유형 **웹 앱** 선택.
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 3. 사이트에 연결
1. `job-dictionary/data/site.json` 의 `formEndpoint` 에 그 URL을 붙여 넣습니다.
2. `python build.py` 로 다시 빌드하고 배포합니다.
3. 사이트 폼에서 테스트 신청을 하나 보내 시트에 들어오는지 확인합니다.

## 4. 카카오톡 알림 설정 (선택, 약 10분)

신청이 들어오면 **내 카카오톡(나와의 채팅)** 으로 "[상담신청] 홍길동 · 중고신입 · 지원직무 인사 / 연락처 / 고민 요약"과 "시트 열기" 버튼이 옵니다.
카카오의 "나에게 보내기" 기능을 쓰므로 카카오 개발자 사이트에서 앱을 하나 만들어야 합니다. 한 번만 하면 됩니다.

1. https://developers.kakao.com 에 **본인 카카오 계정**으로 로그인 → 상단 **내 애플리케이션** → **애플리케이션 추가하기**.
   앱 이름은 `취업조로 알림`, 회사명은 `커리어프로젝트` 처럼 아무거나 적고 저장합니다.
2. 만든 앱을 열고 **앱 키** 메뉴에서 **REST API 키**를 복사해 둡니다. (JavaScript 키, Admin 키가 아니라 REST API 키입니다)
3. 왼쪽 메뉴 **카카오 로그인** → 활성화 설정을 **ON** 으로 켜고, 아래 **Redirect URI** 에 `https://localhost` 를 등록(저장)합니다.
   - 같은 메뉴의 **보안 > Client Secret** 은 "사용 안 함" 그대로 두는 것이 간단합니다. (켰다면 그 값을 5번에서 `KAKAO_CLIENT_SECRET` 로 함께 저장하세요)
   - 왼쪽 **플랫폼** 메뉴에서 **Web 플랫폼 등록** → 사이트 도메인에 `https://docs.google.com` 을 넣어 두면 "시트 열기" 버튼이 확실히 동작합니다. (등록하지 않으면 버튼 없이 본문에 링크만 들어간 메시지로 보냅니다)
4. 왼쪽 메뉴 **카카오 로그인 > 동의항목** → **카카오톡 메시지 전송 (talk_message)** 의 "설정" → **선택 동의** 로 저장합니다.
   (이 항목이 안 보이면 **카카오 로그인** 활성화가 먼저 켜져 있어야 합니다)
5. 구글 시트 → **확장 프로그램 > Apps Script** → 왼쪽 톱니바퀴 **프로젝트 설정** → 맨 아래 **스크립트 속성 > 스크립트 속성 추가**:
   - 속성 `KAKAO_REST_KEY`, 값 = 2번에서 복사한 REST API 키 → **스크립트 속성 저장**.
   - 나머지 속성(`KAKAO_REFRESH_TOKEN`, `KAKAO_ACCESS_TOKEN`, `KAKAO_ACCESS_EXPIRES`)은 코드가 알아서 만들고 갱신하니 직접 넣지 않습니다.
6. 편집기로 돌아와 코드를 최신 `google/apps_script.gs` 로 바꿔 넣고 저장한 뒤, 함수 선택 상자에서 **`kakaoAuthUrl`** 을 고르고 ▶ 실행.
   (처음이면 권한 승인 창이 뜹니다 → 본인 구글 계정 → 고급 → 이동 → 허용. "외부 서비스에 연결" 권한이 새로 추가됩니다)
   아래 **실행 로그**에 `https://kauth.kakao.com/oauth/authorize?...` 로 시작하는 URL 이 나옵니다.
   그 URL 을 복사해 **브라우저 새 탭**에 붙여 넣고 → 카카오 로그인 → **[동의하고 계속하기]**.
   화면은 "localhost에 연결할 수 없음"처럼 깨져 보여도 정상입니다. **주소창**을 보면 `https://localhost/?code=XXXXXXXX` 로 바뀌어 있습니다.
   `code=` 뒤의 값(끝까지 전부)을 복사합니다.
7. 편집기 맨 위쪽 `var KAKAO_AUTH_CODE = "";` 의 따옴표 안에 방금 복사한 코드를 붙여 넣고 저장(Ctrl+S) → 함수 선택 상자에서 **`kakaoExchangeCode`** 를 고르고 ▶ 실행.
   실행 로그에 `카카오 토큰 저장 완료. scope=talk_message` 가 보이면 성공입니다. 이후 `KAKAO_AUTH_CODE` 는 다시 `""` 로 비워 두세요.
   - 인가 코드는 1회용이고 몇 분 안에 만료됩니다. 실패하면 6번부터 다시 하세요.
   - `KOE010` 등 오류가 나면 REST API 키가 맞는지, Redirect URI 가 `https://localhost` 로 정확히 등록됐는지 확인하세요.
8. 함수 선택 상자에서 **`kakaoTest`** 를 고르고 ▶ 실행 → 휴대폰 카카오톡 **"나와의 채팅"** 에 테스트 메시지가 오면 끝입니다.
   안 오면 실행 로그의 오류 내용을 보세요. (`insufficient scopes` → 4번 동의항목 확인 후 6~7번 다시 / `401` → 6~7번 다시)
9. **배포 > 배포 관리 > 연필(수정) > 버전: 새 버전 > 배포** 로 재배포합니다. 이걸 해야 실제 사이트 폼에서 들어오는 신청에 새 코드가 적용됩니다. URL은 바뀌지 않습니다.
10. (선택) 편집기 왼쪽 **시계 아이콘(트리거) > 트리거 추가** → 함수 `kakaoKeepAlive`, 이벤트 소스 "시간 기반", "주 단위 타이머" 로 저장해 두면 신청이 오래 없어도 토큰이 만료되지 않습니다.

### 카카오톡 알림 주의사항
- **refresh token 유효기간은 약 2개월**이고, 알림을 보낼 때마다(정확히는 토큰을 갱신할 때마다) 자동으로 연장됩니다. 두 달 넘게 신청이 하나도 없으면 만료될 수 있으니 10번의 트리거를 걸어 두거나, 만료되면 6~9번을 다시 하면 됩니다.
- 메시지는 카카오 "**나에게 보내기**"라서 **인증한 본인 카카오톡(나와의 채팅)에만** 옵니다. 다른 사람에게는 가지 않습니다.
- 카카오 전송이 실패해도 **시트 기록과 이메일 알림은 그대로** 갑니다. 신청자 화면에도 "접수 완료"로 나옵니다. 실패 원인은 Apps Script 왼쪽 **실행** 메뉴의 기록에서 볼 수 있습니다.
- 본문은 카카오 제한(200자) 때문에 고민 내용을 80자까지만 보여 줍니다. 전체 내용은 시트나 이메일에서 확인하세요.
- REST API 키와 토큰은 코드가 아니라 스크립트 속성에만 있으니, 코드를 공유하더라도 속성 값은 공유하지 마세요.

## 참고
- 스크립트를 수정하면 **배포 > 배포 관리 > 연필 > 버전: 새 버전 > 배포** 를 눌러야 반영됩니다. URL은 그대로입니다.
- claude.ai 미리보기(Artifact)에서는 보안 정책 때문에 전송이 막힙니다. 실제 배포 주소(GitHub Pages 등)나 로컬 파일에서 테스트하세요.
- 시트의 `처리상태` 열은 담당자가 직접 적는 칸입니다 (신규 → 연락완료 → 상담예약 → 종료 등).
- 전송 데이터에는 신청자가 입력한 값과 함께 신청 페이지·직무사전 직무 ID가 들어갑니다. 개인정보는 시트 공유 범위를 본인으로만 두세요.
